Type in any U.S. ZIP code and see one simple chart: flu cases over the past 26 weeks in that state, what was expected for the most recent week based only on the weeks before it, and how close that expectation was. The orange dashed line shows what the forecast would have guessed for each of those earlier weeks, so you can see how well it tracked flu cases along the way.

Flu cases are patients seen with flu-like illness, reported to the CDC for the whole state — the CDC publishes this data by state, so a ZIP code is matched to its state. The solid teal line is what really happened; the dashed orange line is what the forecast would have guessed for each past week, using only the weeks before it. Hover or tap any point for that week’s numbers.

How this check works, in plain English

  1. Find your state. Your ZIP code tells us your state, and we use that state’s flu cases reported to the CDC.
  2. Look back, then guess the latest week. The forecast is made using only the previous 25 weeks. It does not see the most recent week until after the guess is made — that is the fair test.
  3. See how it did on the way. The dashed orange line on the chart repeats that same one-week-ahead guess for each earlier week, so you can see whether the forecast usually stayed close to what really happened.
  4. Compare the guess to reality. We show the difference in both cases and percent. If the most recent week came in more than 3% higher than expected, the chart flags it — the same early-warning idea used in the original project.

Technical details: the forecast is an ARIMA time-series model, chosen automatically from several candidates (see the panel beside this one).

Data: CDC FluView (ILINet) via the CMU Delphi Epidatas API — the same source the repo’s cdc_flu_pipeline.py fetches. Snapshot pulled Oct 17, 2026; most states run through MMWR week 2026-W40 (week starting Oct 4, 2026). Eight states (AK, CT, HI, NY, OK, OR, SD, UT) have a reporting gap in the FluView feed after Sep 2025, so for their ZIPs the figure uses their most recent 26 continuous reported weeks and says so on the chart. The newest FluView issue is preliminary: where a state’s latest week arrived with a collapsed patient count (a reporting-lag signature, e.g. Texas), the window ends at its last complete week instead. FluView does not publish flu case counts for American Samoa, Guam, or the Northern Mariana Islands.

Technical details about the model: this page implements the ARIMA design described in the technical panel above, fit live in your browser on the previous 25 weeks. The production repo trains a LightGBM model on multi-year history and emails an 8-week chart with the same +3% above-prediction alert.
